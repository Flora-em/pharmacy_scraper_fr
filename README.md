Objectif : Scraping des avis Google Maps des pharmacies de France métropolitaine (hors outre-mer)<br>

Missions : <br>

Construction d'une base de données propre pour le scraping,<br>
Scraping des avis des pharmacies de France,<br>
Nettoyage et rassemblement des données des différents collègues.<br>

- Auvergne-Rhône-Alpes
- Bourgogne Franche-Comté

- Bretagne
- Corse

Outils :
- data.gouv
- Python
- Playwright
